`main.py` validates the one-line entry (1–200 characters, single line,
UTF-8, no control characters) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a
byte-level read-back check. It never writes into the repository itself.
